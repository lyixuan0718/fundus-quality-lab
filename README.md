# Fundus Quality Lab：眼底影像品質互動實驗室

親手調整模糊、曝光與對比，即時觀察眼底影像與品質指標如何跟著變化的教育用互動網頁。

**Live Demo：** https://lyixuan0718.github.io/fundus-quality-lab/

## 主要功能

- **合成示範影像**：開啟網頁即自動載入程式生成的眼底影像（非真實病患影像），不需上傳即可操作。
- **上傳影像**：支援 JPG、PNG、WebP（單張、10MB 以內、寬高至少 256px），並提供格式、大小、解析度等錯誤提示。
- **三種劣化滑桿**：模糊（0–10 px）、曝光（−2 至 +2 EV）、對比（0.30–2.00×）。
- **分割比較**：拖曳分割線或使用下方滑桿，左右對照原圖與調整後影像。
- **五項影像指標**：平均亮度、對比度（灰階標準差）、清晰度（Laplacian 變異數）、過曝比例、欠曝比例，同時顯示原始值、目前值與變化量。
- **情境預設**：對焦失準、曝光不足、曝光過度、低對比，一鍵套用參數。
- **輔助說明**：每項指標的白話說明、灰階直方圖，以及可開關的計算區域虛線圓。
- **響應式設計**：桌面版為主，手機也能完成基本操作。

## 三步驟操作方式

1. 使用內建的合成示範影像，或上傳一張自己的圖片。
2. 拖動模糊、曝光、對比滑桿，或點選情境預設。
3. 拖曳分割線比較原圖與調整後影像，並觀察指標變化。

## 技術特色

- **單一 index.html**：HTML、CSS、JavaScript 與示範影像的生成程式都在同一個檔案中。
- **原生 HTML / CSS / JavaScript**：不使用框架，也不需要建置步驟。
- **Canvas 2D**：所有影像處理與指標計算都以 Canvas 2D 與原生 JavaScript 完成。
- **無外部套件**：不載入 CDN、網路字體、外部圖片或 API。
- **可離線執行**：載入後不需網路；直接下載 index.html 以瀏覽器開啟也能使用。

## 隱私說明

所有影像只在使用者的瀏覽器本機處理，不會上傳或儲存；網站也不使用任何分析或追蹤工具。

## 免責聲明

本工具僅供影像處理與教育展示，不具醫療診斷、篩檢或臨床品質判定用途。
